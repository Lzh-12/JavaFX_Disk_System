# SCAU 操作系统课程设计-模拟磁盘文件系统实现

* 课程设计题目 ：模拟磁盘文件系统实现
* 实现技术：基于Java和JavaFx图形化实现
* 作者：Lzh
* 完成时间：大三上学期


## 课程设计内容
* 设计一个简单的文件系统，用文件模拟磁盘，用数组模拟缓冲区，要求：
* （1） 支持多级目录结构，支持文件的绝对读路径；
* （2） 文件的逻辑结构采用流式结构，物理结构采用链接结构中的显式链接方式；
* （3） 采用文件分配表 FAT；
* （4） 实现的命令包括建立目录、列目录、删除空目录、建立文件、删除文件、显示文件内容、 打开文件、读文件、写文件、关闭文件、改变文件属性。
* （5） 最后编写主函数对所作工作进行测试。


## 用户操作手册
### 文件操作命令
* 建立文件：create 文件名 文件属性
* 打开文件：open 文件名 操作类型
* 读文件：read 文件名 读入的字节数
* 写文件：write 文件名 内容
* 关闭文件：close 文件名
* 删除文件：delete 文件名
* 显示文件：cat 文件名
* 改变文件属性：chmod 文件名 文件属性

### 目录操作命令
* 建立目录：mkdir 目录名
* 显示目录内容：ls [目录名]
* 删除空目录：rmdir 目录名
* 切换目录：cd 目录名

### 其他操作命令
* 显示文件系统的磁盘空间使用情况：df
* 格式化磁盘：mkfs
* 查看命令：help
* 清屏：clear
* 退出：quit

## 程序特点
* 支持多级树形目录
* 支持相对路径
* 图形化界面
